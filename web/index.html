    01

    Create socket

    socket()

    Creates a communication endpoint that a program can use for network communication.

    Gateway + C server
    02

    Prepare server

    bind() → listen()

    The C server attaches its address and port, then waits for incoming connections.

    C server
    03

    Connect

    connect() → accept()

    The Python Gateway requests a TCP connection; the C server accepts it.

    Gateway + C server
    04

    Exchange data

    send() ↔ recv()

    The Gateway sends a command and receives the C server's response over the connected socket.

    Both ends
    05

    Close connection

    close()

    The socket is closed when the session ends or the connection is cleaned up.

    Both ends

    Note: the C server usually creates its listening socket at startup. The Gateway connects when it needs a server session. Your Gateway keeps that TCP connection open for the browser session, so steps 1–3 do not repeat for every deposit or balance request; send/receive is used for each command.
